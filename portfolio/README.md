# Malik Sharia - Personal Portfolio

Responsive portfolio built for the MTech Solutions Frontend Development Internship (Batch 01, Task 01).

## Technologies
HTML5, CSS3 (Grid, Flexbox, custom properties), vanilla JavaScript (ES6), Google Fonts.

## Sections
Hero, About Me, Skills, Projects (3 working demos in `projects/`), Services, Contact form (validated), Footer.

## Run locally
No build step. Open `index.html` in a browser, or run `npx serve .`

## Deploy
- Netlify: drag the folder to app.netlify.com/drop
- Vercel: import the GitHub repo at vercel.com/new (Framework: Other)

## Structure
```
portfolio/
  index.html
  css/style.css
  js/main.js
  projects/
  assets/
```
